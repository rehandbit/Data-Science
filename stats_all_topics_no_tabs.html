Types of data
Q1What are the types of data? Full tree with subcategories.
▼
All Data
Qualitative (Categorical) — describes labels or groups
Nominal — no natural order. e.g. colour, gender, country, blood type
Ordinal — has order, but gaps between ranks are unequal. e.g. star ratings 1–5, grades A/B/C, survey: agree/neutral/disagree
Quantitative (Numerical) — measured in numbers
Discrete — countable whole numbers. e.g. number of children, number of clicks, number of cars
Continuous — any value in a range (infinite possibilities)
Interval — equal gaps, but NO true zero. e.g. temperature in °C, IQ, calendar year (0°C ≠ no temperature)
Ratio — equal gaps + TRUE zero. e.g. height, weight, income, age (£0 = no money)
Say this
"Data splits into qualitative and quantitative. Qualitative describes categories — nominal has no order like country names, ordinal has order but unequal gaps like star ratings. Quantitative is numerical — discrete is countable like number of purchases, continuous can be any value. Continuous further splits into interval, which has equal gaps but no true zero like Celsius temperature, and ratio which has a true zero like income or height."
Classic trap question
"Is temperature interval or ratio?" — Celsius and Fahrenheit are interval (0° doesn't mean 'no heat'). Kelvin is ratio (0K = absolute zero = true zero). Get this right and you'll impress.
Q2Why does data type matter — what changes based on it?
▼
NominalOnly mode for central tendency. Chi-square test. One-hot encoding in ML. Bar charts / pie charts.
OrdinalMedian not mean. Spearman not Pearson correlation. Label encoding preserving order.
Interval / RatioMean, std dev, Pearson correlation. All parametric tests. Histogram, box plot.
DiscreteCount data — use Poisson distribution. Bar chart, not histogram.
ContinuousHistogram, box plot, density plot. Normal distribution may apply.
Say this
"Data type dictates everything downstream — which summary statistics are valid, which charts to use, which statistical tests to run, and which ML preprocessing is needed. Using mean on ordinal data or Pearson on categorical data gives meaningless results. Data type identification is always my first step."
Correlation
Q3What is correlation? How do you interpret it?
▼

Measures strength and direction of linear relationship between two variables. Range: −1 to +1.

+1Perfect positive — as one increases, other always increases proportionally.
0No linear relationship. (Note: could still have a non-linear relationship.)
−1Perfect negative — as one increases, other always decreases.
0.7 to 1Strong. 0.4–0.7 = moderate. 0–0.4 = weak.
Pearson r = Σ[(x−x̄)(y−ȳ)] / [n × σx × σy]
Say this
"Correlation measures how two variables move together — its value ranges from −1 to +1. +1 means perfect positive relationship, −1 means perfect negative, 0 means no linear relationship. Pearson is the standard formula for two continuous normal variables."
Always say this — interviewers expect it
"Correlation does not imply causation." Ice cream sales and drowning rates are correlated — both are caused by hot weather (confounding variable). A spurious correlation without a causal mechanism is meaningless.
Q4Pearson vs Spearman vs Kendall — when to use each?
▼
Pearson
Linear + Normal
Both continuous, normally distributed, linear relationship. Most powerful when assumptions hold.
Spearman
Rank-based
Ordinal data, skewed, or non-linear monotonic relationship. Converts values to ranks first.
Kendall
Small samples
Better for very small samples or data with many tied values. Less common in practice.
Say this
"Pearson is the default for two continuous normally distributed variables with a linear relationship. If the data is ordinal, skewed, or the relationship is monotonic but not strictly linear, I use Spearman — it ranks the values first and then correlates the ranks. Kendall suits small samples with many ties."
Q5What is multicollinearity and why is it a problem?
▼

When two or more predictor features are highly correlated with each other.

Why it's badMakes individual coefficients in linear models unstable and hard to interpret. Small data changes cause large coefficient swings.
How to detectVIF (Variance Inflation Factor). VIF > 5 = concerning, VIF > 10 = serious problem.
How to fixRemove one of the correlated features. Use PCA to combine them. Apply Ridge (L2) regression which handles it well.
Say this
"Multicollinearity is when two or more predictor variables are highly correlated with each other — not just with the target. For example, having both 'height in cm' and 'height in inches' in a model. It makes it impossible to isolate each variable's individual effect. I detect it using VIF scores and fix it by dropping one of the correlated variables or using Ridge regression."
Q6What is covariance? How is it different from correlation?
▼
Covariance = Σ[(x−x̄)(y−ȳ)] / n (has units, unbounded)
Correlation = Covariance / (σx × σy) (unitless, bounded −1 to +1)
Say this
"Covariance measures the direction of the relationship between two variables — positive means they move together, negative means they move opposite. But covariance is in the original units of the data, so the magnitude is hard to interpret. Correlation standardises covariance by dividing by both standard deviations, giving a unitless value between −1 and +1 that's easy to compare across different variable pairs. Correlation is just standardised covariance."
Assumption of normality
Q7What is the assumption of normality?
▼

Many statistical tests assume data — or model residuals — follow a bell-curve (normal) distribution.

Assumes normalityt-test, ANOVA, linear regression (residuals), Pearson correlation, z-test.
Do NOT require itMann-Whitney, Kruskal-Wallis, Spearman, chi-square, tree-based ML models.
Say this
"The normality assumption means the data or the model's residuals follow a normal bell-curve distribution. Tests like t-tests and ANOVA rely on this — if violated, their p-values and confidence intervals may be inaccurate. For linear regression specifically, it's the residuals that need to be normal, not the raw data — that's a common confusion."
Key nuance interviewers love
In linear regression, you check residuals for normality — NOT the target variable. Many candidates get this wrong.
Q8How do you test for normality?
▼
HistogramQuick visual. Does it look bell-shaped? Good first check.
Q-Q plotPlots data quantiles against a theoretical normal. Points on the diagonal line = normal. Best visual method.
Shapiro-Wilk testStatistical test. H₀: data is normal. p > 0.05 = approximately normal. Best for small samples (n < 50).
Kolmogorov-SmirnovSimilar but better for large samples. Compares empirical vs theoretical distribution.
Say this
"I start with a Q-Q plot — if points fall on the diagonal the data is approximately normal. For a formal test I use Shapiro-Wilk for small samples. However, with very large datasets even tiny, irrelevant deviations appear significant, so I rely more on the Q-Q plot than the p-value."
Q9What do you do if data is not normal?
▼
TransformLog, sqrt, or Box-Cox transform makes right-skewed data more symmetric.
Non-parametric testMann-Whitney instead of t-test. Kruskal-Wallis instead of ANOVA. Spearman instead of Pearson.
Use CLTWith n > 30, Central Limit Theorem guarantees the sampling distribution of the mean is approximately normal regardless of the raw data.
Say this
"If data violates normality I have three options: transform it using log or sqrt to make it more symmetric, switch to a non-parametric equivalent test that doesn't require normality, or rely on the Central Limit Theorem — with large enough samples the mean is approximately normal regardless of the underlying distribution."
Normalisation and standardisation
Q10What is the difference between normalisation and standardisation?
▼
Normalisation — Min-Max
Scales to [0, 1]
Subtracts min, divides by range. Bounded output. Sensitive to outliers — one extreme value compresses everything else.
Standardisation — Z-score
Mean=0, Std dev=1
Subtracts mean, divides by std dev. No fixed range. Robust to outliers. Keeps distribution shape.
Normalisation: x_new = (x − min) / (max − min)
Standardisation: x_new = (x − mean) / std_dev
Say this
"Normalisation rescales to 0–1 using min-max. Standardisation rescales to mean 0 and std dev 1. The key difference is outlier sensitivity — one extreme value in normalisation squashes all other values into a tiny range. Standardisation is more robust and is the safer default for most ML algorithms."
Data leakage trap — always mention this
Always fit the scaler on training data only, then apply to test data. Fitting on the full dataset leaks test set statistics into training — a very common mistake.
Q11When to use which? And when is neither needed?
▼
Use standardisationLinear/logistic regression, SVM, KNN, PCA, neural networks. Default choice when no specific reason to bound.
Use normalisationNeural networks processing image data (pixels 0–255 → 0–1). When bounded range is explicitly needed.
Neither neededDecision trees, Random Forest, XGBoost, LightGBM. Tree-based models split on thresholds — scale doesn't matter.
Say this
"Standardisation is my default for most algorithms — especially distance-based ones like KNN and SVM where scale directly affects results. Normalisation suits bounded inputs like image pixels going into a neural network. Tree-based models like Random Forest and XGBoost are scale-invariant — they don't need either."
Sampling
Q12What is sampling and what are its types?
▼

Selecting a subset of a population to draw conclusions about the whole.

Probability sampling — every member has a known chance
Simple randomEvery member equally likely. Most unbiased. e.g. random number generator picks 500 from 50,000.
StratifiedDivide into subgroups (strata), randomly sample from each. Best when subgroups matter. e.g. equal samples from each age group.
SystematicPick every Nth member. e.g. every 10th customer from a list. Simple but can introduce pattern bias.
ClusterDivide into clusters, randomly pick whole clusters. Cost-effective for geographically spread populations.
Non-probability sampling — selection not random
ConvenienceWhoever is easiest to reach. Fast, highly biased. Can't generalise statistically.
PurposiveDeliberately select specific people. e.g. only domain experts for a specialist study.
SnowballExisting participants recruit more. Used for hard-to-reach groups.
Say this
"Probability sampling gives every member a known chance of selection and produces representative samples valid for statistical inference. Stratified is my preferred method when the population has important subgroups I want to ensure are represented. Non-probability methods are faster but biased — results can't be generalised to the full population."
Q13What are the types of sampling bias?
▼
Selection biasSample not representative. e.g. online survey only captures people with internet access.
Survivorship biasStudying only survivors. e.g. analysing only successful startups to find success factors — ignoring all failed ones skews every conclusion.
Response biasRespondents answer inaccurately. e.g. overreporting exercise, underreporting unhealthy habits.
UndercoverageSome population groups excluded or underrepresented entirely.
Confirmation biasResearcher unconsciously collects data that confirms existing beliefs.
Say this
"The most important type to know is survivorship bias — it leads to completely wrong conclusions by ignoring failures. If you study only successful companies to find what makes a startup succeed, you're missing all the companies that did the same things and failed. Always ask: what data am I not seeing?"
Resampling
Q14What is resampling? Bootstrap vs cross-validation?
▼

Creating multiple samples from the same dataset to estimate performance or statistical variability.

Bootstrap
Sample with replacement
Draw N samples, allowing repeats. Repeat many times. Used to estimate confidence intervals and variability of any statistic. Each bootstrap sample is the same size as original.
Cross-validation
Rotate test folds
Split into k folds, rotate which is test. Used to estimate how well a model generalises. Every data point is used for testing exactly once.
Say this
"Resampling creates multiple datasets from one original. Bootstrap samples with replacement — same point can appear multiple times — and is used to estimate the variability of statistics like the mean or a model coefficient. Cross-validation splits data into folds and rotates the test set to evaluate model performance. Bootstrap is about measuring uncertainty of statistics, cross-validation is about evaluating models."
Q15What are the types of cross-validation?
▼
K-foldSplit into k equal parts. Train on k−1, test on 1, rotate. Average k scores. Standard choice. Typically k=5 or k=10.
Stratified k-foldSame as k-fold but ensures each fold has the same class distribution. Essential for imbalanced classification.
Leave-one-out (LOO)Each single data point is the test set once. Computationally expensive but great for tiny datasets.
Time series splitFor time series — always train on past, test on future. Never shuffle. Prevents data leakage from the future.
Say this
"Standard k-fold is the default — 5 or 10 folds. For classification with imbalanced classes I always use stratified k-fold to ensure each fold represents the class distribution correctly. For time series data I use time series split where the training window always precedes the test window — shuffling would be data leakage."
Univariate, bivariate and multivariate analysis
Q16What is univariate analysis?
▼

Analysing one variable at a time — understanding its distribution, center, and spread.

Numerical dataMean, median, mode, std dev, variance, IQR, skewness, kurtosis, percentiles. Plots: histogram, box plot, density plot.
Categorical dataFrequency count, mode, percentage. Plots: bar chart, pie chart.
GoalUnderstand shape, spot outliers, check for missing values, decide if transformations are needed.
Say this
"Univariate analysis examines one variable at a time. For numerical columns I check distribution shape with a histogram, identify outliers with a box plot, and compute central tendency and spread. For categorical columns I count frequencies and plot a bar chart. It's the mandatory first step of EDA — you must understand each feature individually before looking at relationships."
Q17What is bivariate analysis?
▼

Analysing the relationship between two variables.

Num vs NumScatter plot. Pearson or Spearman correlation. Covariance. Trend line.
Cat vs CatContingency table (cross-tab). Chi-square test of independence. Stacked or grouped bar chart.
Num vs CatBox plot by group. Violin plot. t-test for 2 groups. ANOVA for 3+ groups.
Say this
"Bivariate analysis looks at the relationship between two variables. For two numerical variables I use scatter plots and correlation. For two categorical variables I build a contingency table and run a chi-square test to check if they're independent. For numerical versus categorical — like salary by job title — I plot box plots per group and use a t-test or ANOVA to test if group differences are statistically significant."
Q18What is multivariate analysis?
▼

Analysing three or more variables simultaneously to find complex relationships and patterns.

Correlation heatmapShows pairwise correlations between all numerical features at once. Go-to starting point for multivariate EDA.
Pair plotGrid of scatter plots between all feature pairs. Quickly reveals clusters, correlations and outliers across all combinations.
PCAReduces many features into fewer components that capture maximum variance. Used for visualisation and removing multicollinearity.
Multiple regressionModels relationship between one target and multiple features simultaneously. Shows each feature's effect controlling for others.
Clustering (K-means)Groups observations based on patterns across many features at once. Unsupervised multivariate technique.
Say this
"Multivariate analysis handles three or more variables simultaneously. My first step is always a correlation heatmap — it shows every pairwise relationship in one view and immediately reveals multicollinearity. A pair plot gives scatter plots for every feature pair. For high-dimensional data I use PCA to reduce dimensions while preserving variance. Multiple regression quantifies each feature's effect on the target while controlling for all the others."
Q19What is EDA and what is your process?
▼
Step 1Shape, dtypes, .info(), .describe() — understand size and data types.
Step 2Missing values — count per column, decide strategy (impute or drop).
Step 3Univariate — distribution, outliers, skewness for each feature.
Step 4Bivariate — relationship of each feature with the target variable.
Step 5Multivariate — correlation heatmap, pair plot, feature interactions.
Step 6Document findings — what needs encoding, scaling, transformation, or dropping.
Say this
"EDA is how I understand a dataset before building any model. I start with shape and dtypes, then check missing values, then do univariate analysis on each feature to understand distributions and outliers, then bivariate analysis between features and the target to understand what's predictive, then a correlation heatmap for the full multivariate picture. EDA drives all my preprocessing and modelling decisions."
Quartiles and IQR — quick recap
Q20Percentile, quartile, IQR — one clean answer.
▼
PercentileNth percentile = value below which N% of data falls. It's a rank, not a count.
Q1 = P2525% of data falls below this. Lower quartile.
Q2 = P50The median. 50% falls below.
Q3 = P7575% of data falls below. Upper quartile.
IQR = Q3 − Q1Spread of middle 50%. Robust — not distorted by outliers.
Outlier fencesBelow Q1 − 1.5×IQR or above Q3 + 1.5×IQR = outlier. Used in box plots.
Say this
"Percentile is a rank — the 90th percentile means 90% fall below you. Quartiles are four named percentiles at 25, 50, 75%. IQR is Q3 minus Q1 — the spread of the middle 50% — and is robust to outliers because it completely ignores the extreme 25% on each side. Tukey's fences use IQR to flag outliers, which is what box plots visualise."
